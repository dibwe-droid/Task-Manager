## Overview

This project is broken down into **8 sprints**, each designed to produce a working, testable increment of the application.

**Sprint Duration:** 1 week each (adjust based on availability)  
**Total Timeline:** 8 weeks  
**Approach:** Backend-first, then frontend integration

### Sprint Summary

| Sprint | Focus | Key Deliverable |
|--------|-------|-----------------|
| 1 | Setup | Project structure |
| 2 | Backend Core | Task CRUD API |
| 3 | Backend Features | Filtering, Projects |
| 4 | Backend Polish | Subtasks |
| 5 | Frontend Setup | Basic UI |
| 6 | Frontend Core | Task CRUD UI |
| 7 | Frontend Features | Filters, Projects, Subtasks |
| 8 | Polish & Deploy | Deployed app |

For detailed tasks, deliverables, and acceptance criteria for each sprint, see the individual sprint files in the [sprints folder](sprints/).
